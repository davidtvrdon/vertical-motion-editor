# Agent instructions (Codex, Cursor, Gemini CLI, Claude Code, …)

This repository is an AI-agent skill plus the Remotion engine it drives: it edits talking-head **vertical video** (9:16) with motion graphics,
b-roll, captions and a branded outro.

**Read `.claude/skills/vertical-motion-editor/SKILL.md` first.** It is the complete playbook (written for any agent that can run shell commands and
look at images; the folder name is just where Claude Code looks for skills). Its `references/` folder holds the details.

Quick orientation:
1. `python3 scripts/doctor.py` tells you what is installed and configured. If something required is missing, or `brand/brand.json` does not exist,
   follow `.claude/skills/vertical-motion-editor/references/onboarding.md` (install → the user's own free Pexels key → brand materials → visual style → outro).
2. To edit a video: `new_project.py` → `transcribe.py` → write `projects/<name>/plan.json` → `pexels.py fill` → `validate_plan.py` → `review.mjs` (look at the stills!) → `render.sh`.
3. Colours, font and box style come from the theme (`src/theme/active.json`, generated by `scripts/apply_brand.py` from `brand/brand.json` and a preset). Do not hard-code colours.
4. Secrets: `.env` is gitignored. Never print, invent or commit API keys. The Pexels key belongs to the user.
5. Media never goes into git; only `projects/<name>/brief.md` and `plan.json` do. Run `npm run typecheck` after changing `src/`.

Installing the skill into another agent's skills folder (optional): `bash scripts/install_skill.sh <target-dir>`; see README.
